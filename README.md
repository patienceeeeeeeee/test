## 关于我

我是 Wong，也叫 Miles，处在职业起步阶段，有电气工程背景，关注制造业现场和小家电产品。

这里是我的公开思考笔记：记录工作与阅读带来的问题，尝试把技术、经营和个人选择之间的关系说清楚。我希望留下的不只是结论，也有形成结论时的依据，以及后来改变判断的原因。

这些文字是阶段性的认识。它们会随着新的信息与实践继续修订。

## 我关注的问题

| 主题 | 我想弄清楚的问题 |
| --- | --- |
| **制造业现场** | 异常来自哪里？如何把测量结果、工艺条件和交付要求联系起来，而不是只盯一个指标？ |
| **小家电与经营** | 一个功能到底替用户解决了什么问题？产品成本、质量与售后，怎样支撑它的定位？ |
| **职业成长** | 怎样把“学过”变成能解释、能交付的能力？在权限有限时，先做哪一件事才有结果？ |
| **人物与阅读** | 决策者当时知道什么、有哪些选择、承担了什么代价？换一个条件，原来的方法还成立吗？ |

## 我希望怎样写

- **从具体事情开始。** 先交代发生了什么，再表达看法。
- **给判断留下依据。** 不把当事人自述当成全部事实，也不把公司成果归给一个人。
- **让结果能够推翻想法。** 记录哪些条件会改变结论，承认还没有答案的部分。
